# CyberQuiz — ระบบแบบทดสอบออนไลน์ Cyber Security Awareness

เว็บแอป PHP + MySQL สำหรับจัดแบบทดสอบก่อน/หลังเรียน (Pretest / Posttest) พร้อมสถิติ แบบประเมินการอบรม และเกียรติบัตร PDF

## ความสามารถ
- ลิงก์ Pretest / Posttest แยกกัน (บังคับทำ Pretest ก่อนได้) — จับคู่ผลด้วยชื่อ-สกุล
- สุ่มข้อสอบจากคลังให้แต่ละคน และสลับลำดับตัวเลือก ตรวจคะแนนฝั่งเซิร์ฟเวอร์
- แดชบอร์ดผู้ดูแล: คะแนนเฉลี่ย, พัฒนาการ Pre→Post, ร้อยละตอบถูกรายข้อ, สรุปตามหน่วยงาน, ผลแบบประเมิน, ค้นหาชื่อ, แก้ไขชื่อ
- เกียรติบัตร PDF (สร้างในเบราว์เซอร์ด้วย jsPDF) — เปลี่ยนภาพพื้นหลัง/ตำแหน่ง/ขนาด/สีได้, บังคับทำแบบประเมินก่อนดาวน์โหลดได้
- ส่งออกเกียรติบัตรทั้งหมดตามวันที่เป็น ZIP และส่งออกผลเป็น CSV

## ความต้องการ
- PHP 7.4 ขึ้นไป (มี `pdo_mysql`, `mbstring`)
- MySQL 5.7+ / MariaDB 10.3+
- ทดสอบบน XAMPP (Windows) และ cPanel shared hosting

## ติดตั้ง
1. วางโฟลเดอร์ไว้ใต้ web root เช่น `C:\xampp\htdocs\cyberquiz`
2. คัดลอก `config.example.php` เป็น `config.php` แล้วแก้ค่าฐานข้อมูลและ **`admin_password`**
3. (ถ้ามี) วางคลังข้อสอบจริง:
   - `inc/seed.php` — ข้อสอบตั้งต้น ใช้ตอนติดตั้งครั้งแรก (ถ้าไม่มี ระบบใช้ `inc/seed.example.php`)
   - `inc/bank2.php` — คลังข้อสอบเพิ่มเติม นำเข้าอัตโนมัติครั้งเดียว (ดูรูปแบบจาก `inc/bank2.example.php`)
4. เปิด `http://localhost/cyberquiz/` — ระบบสร้างฐานข้อมูลและตารางให้อัตโนมัติ
5. หน้าผู้ดูแล: `http://localhost/cyberquiz/admin/`

> ข้อสอบแก้ไข/เพิ่ม/ลบได้ภายหลังที่ **ผู้ดูแล › จัดการข้อสอบ** (ข้อมูลอยู่ในฐานข้อมูล)

## ลิงก์สำหรับผู้เข้าร่วม
| หน้า | URL |
|---|---|
| ก่อนเรียน | `/cyberquiz/pretest.php` |
| หลังเรียน | `/cyberquiz/posttest.php` |

ให้เครื่องอื่นในห้องอบรมเข้าได้: ต่อเครือข่ายเดียวกัน แล้วใช้ลิงก์ IP ที่แสดงบนแดชบอร์ด (อนุญาต Apache ใน Windows Firewall)

## ขั้นตอนในวันอบรม
1. ก่อนเริ่ม: เปิด Pretest / ปิด Posttest (เมนูในแดชบอร์ด)
2. จบการบรรยาย: ปิด Pretest / เปิด Posttest
3. ผู้เข้าร่วมใช้ชื่อ-สกุลเดียวกันทั้ง 2 ครั้ง
4. ดาวน์โหลด CSV แล้วค่อย "ล้างผลการทดสอบ" เมื่อเริ่มรุ่นใหม่

## โครงสร้างไฟล์
```
config.example.php     ตัวอย่างค่าตั้งค่า (คัดลอกเป็น config.php)
pretest.php / posttest.php / index.php
quiz.php, result.php, eval.php, cert.php
admin/                 แดชบอร์ด, จัดการข้อสอบ, ตั้งค่า/ส่งออกเกียรติบัตร, ส่งออก CSV
inc/                   โค้ดส่วนกลาง + คลังข้อสอบ (ปิดไม่ให้เปิดจากเว็บด้วย .htaccess)
assets/                CSS, JS, โลโก้, ภาพพื้นหลังเกียรติบัตร, ฟอนต์ Sarabun, jsPDF/JSZip
uploads/               ภาพพื้นหลังที่อัปโหลด (ต้องเขียนไฟล์ได้)
```

## ไฟล์ที่ไม่อยู่ใน repo (ดู `.gitignore`)
- `config.php` — มีรหัสผ่านจริง
- `inc/seed.php`, `inc/bank2.php` — คลังข้อสอบจริง
- `uploads/*` — ไฟล์ที่ผู้ดูแลอัปโหลด
